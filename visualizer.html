Rules used

Precedence: ^ (3, right-associative) > * / (2) > + - (1). Operands go straight to the output. "(" is pushed. ")" pops until "(". An operator first pops higher-precedence operators (and equal ones if left-associative), then is pushed.

Complexity: each token is pushed and popped at most once, so time is O(n) and space is O(n).
